# AI Restaurant Agent 🍽️

A hands-on project focused on learing how to build AI-powered applications and restaurant assistants using Python and Large Language Models (LLMs).


## 🎯 Project Goals

The main goal is to learn the technologies and concepts involved in building real-world AI agents, including:
- Connecting Python applications to LLM APIs.
- Prompt engineering and instruction design.
- AI agents and tool calling.
- Conversation context and memory.
- Backend development and API integration.
- Database integration.
- Retrieval-Augmented Generation (RAG).
- Error handling, testing and observability.
- Security and responsible handling of API credentials.
